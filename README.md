# VaultPy — менеджер паролей с локальным хранением и шифрованием.

## Основные функции:

+ Регистрация и вход по мастер-паролю.

+ Добавление, просмотр, редактирование и удаление паролей.

+ Разделение паролей по категориям. Генератор случайных паролей.

+ Поиск по сохранённым записям.

+ Копирование пароля в буфер обмена.

+ Заметки с шифрованием.

+ Автоматическая блокировка хранилища.

---

## Технологии:

+ *Python* — основная логика.

+ *PyQt6* — графический интерфейс.

+ *SQLite* (*sqlite3*) — база данных.

+ *hashlib*, *secrets* — мастер-пароль и генерация паролей.

+ Простое собственное шифрование на основе XOR и ключевого потока — без сторонних криптографических библиотек.csv, json — экспорт и импорт данных.
