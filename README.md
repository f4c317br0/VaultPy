# VaultPy

VaultPy — менеджер паролей и защищённых заметок,
разработанный на Python с использованием PyQt6 и SQLite.

<img width="1254" height="1254" alt="logo" src="https://github.com/user-attachments/assets/05d909b5-486c-4bef-a74a-4aa1de390741" />


## Возможности

- Регистрация и авторизация пользователей
- Хэширование мастер-пароля
- Шифрование паролей с помощью AES-GCM
- Хранение защищённых заметок
- Создание и управление категориями
- Поиск сохранённых записей
- Генерация случайных паролей

## Используемые технологии

- Python
- PyQt6
- SQLite
- Cryptography
- AES-GCM
- PBKDF2-HMAC-SHA256

## Установка

1. Склонировать репозиторий.
2. Создать виртуальное окружение.
3. Установить зависимости.
4. Запустить приложение.

## Запуск

```bash
  python main.py
```

## Структура проекта

- main.py — графический интерфейс
- database.py — работа с SQLite
- encryption.py — хэширование и шифрование
- database/vault.db — локальная база данных

## Безопасность

Мастер-пароль не сохраняется в открытом виде.
Пароли и содержимое заметок шифруются AES-GCM.
Ключ шифрования формируется из мастер-пароля
с использованием PBKDF2-HMAC-SHA256.
